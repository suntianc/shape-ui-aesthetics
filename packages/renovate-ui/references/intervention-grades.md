# Intervention Grades

The grade is a mandate, not a severity score. It answers one question: **what is the renovation allowed to destroy?** Assign exactly one grade, backed by evidence from the diagnosis; the owner may bound it downward but the honest grade goes on record either way.

## Rebuild — 重建

**Signal.** No coherent system exists: type, color, spacing, and motion accumulated without governing logic, fragments contradict each other across surfaces, or the visual layer fundamentally misfits what the product is (an expert tool dressed as a toy, a craft brand dressed as a dashboard). Internal consistency cannot save a system built on the wrong premise.

**Mandate.** Suspend deference to the current visual layer entirely. Establish a new aesthetic thesis from the product's own meaning, as if creating from zero — then rebuild the visual layer around the preserved skeleton. Information architecture, functionality, and content survive unless separately renegotiated; pixels do not.

**Evidence bar.** Demonstrate the absence or misfit of a system with concrete contradictions (three type scales on one screen; five grays that are almost the same; accent colors with no ledger; motion with no shared physics) or a direct meaning-misfit argument. If a real system is merely dated, that is Remodel, not Rebuild.

## Remodel — 改制

**Signal.** A genuine system exists — someone authored it, its parts agree — but its governing direction is wrong: visibly dated, borrowed from another product category, tone-deaf to the audience, or wearing another platform's conventions (a native app styled as a web marketing page, a reading product styled as an admin console).

**Mandate.** Replace the governing direction — thesis, palette logic, type voice, motion character — while preserving information architecture, layout structure that still serves, and interaction patterns users rely on. Remodel changes what the interface *means*, not what it *does* or where things live.

**Evidence bar.** Name the current direction, show it was deliberate, and argue the misfit from product truth (audience, era, category, platform), not from taste. "I would have chosen differently" is not a Remodel signal.

## Calibrate — 校准

**Signal.** Direction is right; execution is sloppy. The measurable symptoms: parameters outside the exemplar recipes' measured bands — body line-height below reading bands, more than four common duration values, accent color appearing outside any enumerated slot, spacing values off any discrete scale, type hierarchy using three levers where one would do.

**Mandate.** Bring parameters into band and consolidate redundant values. Direction, layout, and identity are out of scope; every change must be defensible as "the same design, executed properly."

**Evidence bar.** Every calibration cites a measured current value and a target band with its reference sources. Calibrate is the only grade whose findings are near-mechanical; if an argument keeps reaching for direction words ("feels dated", "wrong mood"), the grade is not Calibrate.

## Elevate — 拔升

**Signal.** Nothing is measurably wrong and nothing is memorable. The system is consistent, in band, direction-appropriate — and anonymous: no Signature Move, no authored moment, indistinguishable from a competent template.

**Mandate.** Preserve the system as law. Introduce authorship within it: one Signature Move, sharpened voice in microcopy-adjacent surfaces, finishing depth (optical corrections, state transitions, texture) that rewards attention without spending new color or motion budget.

**Evidence bar.** Elevate must first prove the other three grades are not warranted — it is a certificate of health plus a diagnosis of anonymity. Name what would become the product's signature and why it belongs to this product and no other.

## The protected band (all grades)

Real content, working functionality, state truth, accessibility, and data integrity are never inside any mandate. A Rebuild that loses a feature, fabricates content, or regresses accessibility is a failed renovation regardless of how it looks.

## Grading discipline

- One grade per renovation target. Distinct products or clearly independent surfaces may be graded separately; one page never receives two grades.
- Grade from evidence, not from effort appetite. The mandate's size is the owner's decision to bound, not the grader's to pre-soften.
- Record refused mandates: when the owner bounds a Rebuild down to Calibrate, the report keeps the honest grade so future cycles inherit the truth.
