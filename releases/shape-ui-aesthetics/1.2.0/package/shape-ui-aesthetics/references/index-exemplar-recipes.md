# Exemplar Recipe Index

**Decision question:** Does the reconciled direction match a proven system family whose exemplar-measured parameter bands can anchor materialization?

**Material signals:** The aesthetic thesis is set and materialization needs concrete values — palette levels, type scale, spacing, motion tokens; or a draft is drifting toward generic defaults that measured exemplars would discipline.

**Non-signals:** The aesthetic thesis is still unsettled — recipes never precede the thesis. The direction deliberately departs from every known family — then the recipes serve only as counter-examples.

## Recipes are vocabulary, not defaults

Each recipe distills parameter bands, disciplines, and failure modes from multiple measured reference sites. Adopt, adapt, or reject a recipe in service of the established thesis; a deviation needs nothing more than a thesis that can defend it. Never copy one exemplar site's full parameter set — that is cloning, not authorship. Record which recipes were adopted or rejected and why, as part of the direction state.

**Cross-domain handoffs:** Recipes span Color, Information, and Motion concerns; when a recipe discipline conflicts with a loaded capability contract, reconcile through the standard contribution process — recipes carry evidence weight, not veto authority.
